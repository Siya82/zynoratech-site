# zynoratech.co.za

Official website for Zynora Technologies and its products: THUTOra, DashFactor and TMS (Taxi Management System).
Plain static HTML/CSS/JS, no build step needed. Host on GitHub Pages (CNAME is set to zynoratech.co.za).

- `index.html` company home · `thutora.html` · `dashfactor.html` · `tms.html` product pages
- `support.html`, `privacy.html` (DashFactor privacy policy, same URL as before), `404.html`
- `app-ads.txt` must stay at the site root for AdMob.
- Fonts: Poppins, self-hosted (SIL Open Font License, `assets/fonts/OFL.txt`). No cookies, trackers or third-party requests.
